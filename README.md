# YouTube → Markdown для отдельного GPT

Пользователь отправляет GPT ссылку YouTube. GPT вызывает этот сервис и получает скачиваемый `.md` с доступными субтитрами и таймкодами. Текст не сокращается и не переводится.

## Статус

Код сервера, скрипт и инструкции GPT подготовлены. Сервер ещё нужно разместить на HTTPS-хостинге и подключить в редакторе GPT. Само наличие кода в GitHub не запускает сервис. Создание GPT и Actions должно быть доступно в вашем аккаунте ChatGPT.

## Размещение сервера

Требуется Python 3.12 либо Docker. Запускайте **один процесс / один экземпляр**: временные файлы находятся в памяти этого процесса. Хостинг должен принимать HTTPS на порту 443 и направлять запросы на приложение.

Переменные окружения:

| Переменная | Значение |
| --- | --- |
| `API_KEY` | Случайный секрет длиной от 32 символов; только в настройках сервера и GPT, не в GitHub |
| `PUBLIC_BASE_URL` | Адрес сервиса, например `https://your-service.example.com`, без пути |
| `PORT` | Порт приложения, по умолчанию 8000 |

Сгенерировать секрет: `python3 -c "import secrets; print(secrets.token_urlsafe(32))"`.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
# Задайте API_KEY и PUBLIC_BASE_URL в окружении хостинга.
.venv/bin/uvicorn server:app --host 0.0.0.0 --port 8000 --workers 1 --no-access-log
```

Для Docker используйте приложенный `Dockerfile` и передайте переменные средствами хостинга. `/health` возвращает статус. `/openapi.json` выдаёт готовую схему с вашим адресом.

## Настройка GPT

1. Откройте редактор GPT в ChatGPT, создайте GPT с названием **YouTube → Markdown**.
2. В инструкции вставьте содержимое `GPT_INSTRUCTIONS.md`.
3. Добавьте Action. Импортируйте схему по адресу `https://ВАШ-СЕРВЕР/openapi.json`.
4. Выберите авторизацию **API Key → Bearer**, вставьте значение `API_KEY` вашего сервера. Ключ OpenAI API не нужен.
5. Проверьте действие `getYoutubeTranscript` на ссылке видео с доступными субтитрами. Успех означает, что `.md` скачивается и содержит реальный текст. Проверьте также неверную ссылку и видео без субтитров.
6. Сохраните GPT для личного использования и проверьте его в обычном чате. Доступность создания GPT/Actions зависит от аккаунта. Если этих пунктов нет, потребуется иной способ интеграции.

Загрузка Python-файла в «Знания» GPT не заменяет размещение сервера.

## Работа с файлами и ограничения

- Скачиваемая ссылка действует 10 минут, содержит случайный токен и не требует отдельного ключа. Любой обладатель ссылки может скачать файл до истечения срока. Перезапуск сервиса удаляет файлы.
- Файлы держатся в памяти, просроченные записи очищаются при следующем создании файла или обращении к истёкшей ссылке. Максимум 20 файлов по 9 МБ.
- Одновременно обрабатываются до двух запросов. Получение субтитров ограничено 35 секундами.
- Нет субтитров — нет транскрипта. Распознавание аудио не реализовано.
- YouTube может блокировать IP сервера, особенно облачный. Доступ к каждому видео не гарантируется; выбор хостинга требует реальной проверки. `requests` поддерживает стандартные переменные прокси `HTTPS_PROXY`/`HTTP_PROXY`; настройки и пароли прокси храните только в окружении.
- Язык можно указать явно. Иначе предпочитается язык автоматических субтитров, с выбором авторской дорожки того же языка при наличии. Если автоматической дорожки нет, берётся первая доступная. Выбранный язык указан в файле.
- Сам сервис не хранит историю запросов и не пишет текст транскриптов в журналы. Логи обратного прокси/хостинга настраиваются отдельно; не записывайте токены ссылок и заголовки авторизации.

## Отдельный запуск скрипта

```sh
.venv/bin/python transcript.py 'https://www.youtube.com/watch?v=VIDEO_ID'
# Необязательный выбор существующей дорожки:
.venv/bin/python transcript.py 'https://www.youtube.com/watch?v=VIDEO_ID' --language ru
```

Файл: `outputs/VIDEO_ID.md`. Повторная обработка того же ID заменяет файл.

## Проверки

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m unittest discover -s tests -v
```

Восемь локальных проверок покрывают ссылки, Markdown, авторизацию, выдачу и истечение срока файла, схему Action, тайм-аут и блокировку YouTube. Сетевые ответы в тестах сервера заменены контролируемыми примерами; тесты не доказывают доступность YouTube с выбранного хостинга.
